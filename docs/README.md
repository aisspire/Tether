## 资料状态

- 已确认行为：来自用户明确要求及对最终方案的认可，集中维护在基线。
- 建议实现：为满足已确认行为提出的技术方案，实施时可以收敛，但不能改变核心行为。
- 工程待落实：字段、版本、控制通道等不需要反复确认产品方向的细节。
- 已实现：以实现契约和验证记录为准；文档、Git 初始化或设计验收矩阵本身不代表业务能力及所有平台场景已通过。

所有仓库内链接均指向本独立仓库内资料，不依赖 Oriel 的本机路径或被忽略的会话文件。
