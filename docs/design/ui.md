# 界面设计

状态：本文保留已确认的产品要求；已实现部分、准确字段和当前限制见[实现契约](../implementation.md)及[实际验证](../../verification.md)，下文候选方案不等于全部已交付。围绕[当前基线](current-design.md)构建操作界面，不以服务器监控大屏或完整终端产品为目标。

## 1. 风格与布局

与 Oriel 保持同一视觉方向：浅灰与深墨两套主题、系统字体、柔和圆角、细边框、紧凑工具栏和少量状态色。减少介绍性文案和大块指标卡，信息按任务展示。

独立浏览器和 Oriel 嵌入使用同一套页面。样式以本仓库可独立交付的资源为基础，不导入 Oriel 内部 Vue 组件实例或写死其源码路径。主题跟随和样式分发接口可在集成时确定。

2026-10-23 实现使用以下基础色值，透明表面与主题令牌以 `ui/style.css` 为准；色值仍不是插件对外接口：

| --- | --- | --- |
| 页面底色 | `#f4f4f8` | `#171820` |
| 侧栏 | `rgba(250,250,253,.58)` | `rgba(23,24,33,.62)` |
| 卡片表面 | `rgba(255,255,255,.68)` | `rgba(43,45,58,.64)` |

字体起步为 Segoe UI Variable／Segoe UI／PingFang SC／Microsoft YaHei／sans-serif。状态不能只靠颜色区分，保留文字或图标及可访问名称。

### 通透层次与操作精简（2026-10-23 已实现）

在不改变主机、映射、计划、密钥、文件与配置行为的前提下，界面统一为轻透明层次：页面使用低对比径向光晕，侧栏、工具栏和主机卡片使用半透明表面、细边框与轻阴影，避免大块实色面板；弹窗使用实色表面保证表单和说明文字可读。操作层级按任务收紧：

- 侧栏使用图标加名称，窄窗口保留图标并隐藏可见名称，仍提供可访问名称。
- 页头只保留标题、页面摘要以及图标化的“使用说明”“刷新”；主机页主操作仍是“添加主机”，计划页主操作仍是“新建计划”。
- 主机与映射的启动、停止、编辑、复制、更多等次要操作用图标按钮，保留 `aria-label`、`title` 和可见焦点；测试响应、生效参数、临时转发、删除主机等集中到主机“更多”菜单，映射编辑、复制 ID、删除登记与临时项保存集中到映射“更多”菜单。
- 状态和响应时间使用带文字的紧凑标签；映射地址保持等宽字体。计划、密钥、文件和配置继续按任务分组，主要提交动作仍使用文字按钮。
- 正文、说明弹窗和窄屏字号、行高、间距统一；说明正文使用受控阅读宽度，代码块使用轻表面。
- 断点随可用宽度调整侧栏、主机操作行、映射列数、菜单呈现和弹窗内边距。窄屏菜单改为底部浮层，避免横向溢出。

本调整只移动操作入口、图标化次要动作和统一视觉令牌，不增减功能，不改变后台接口、权限边界或生命周期。实际截图与检查结果见[验证记录](../../verification.md)。

## 2. 信息结构

| 页面 | 主要任务 |
| --- | --- |
| 主机 | 管理 SSH 目标、配置与端口映射；查看状态、批量启动、停止和匹配的终端连接状态 |
| 计划 | 按主机选择映射，保存固定启动清单、一键执行并查看结果 |
| 密钥 | 查看文件与 Agent 身份，调用生成、公钥复制、加载等工具 |
| 设置 | 编辑 SSH 原文和本地配置，维护客户端路径与本机偏好 |

导航的最终排列可在实现中调整，保持核心转发任务容易到达。

计划选择中的主机全选仅选择当时已有的规则，保存明确的规则引用集合。主机后续新增映射不自动勾选或加入已有计划；编辑计划时由用户主动选择。

### 使用说明（2026-10-22 已实现）

在 Tether 内提供可点击的“使用说明”入口，独立运行和 Oriel 中均可访问。内容覆盖 OpenSSH 前置条件、独立启动、Oriel 接入、主机／规则／计划、配置与运行快照分离、增量复用、按组停止的影响、关闭页面与完全退出的区别，以及外部 SSH 只读边界。

使用内容以仓库根目录的 [USER_GUIDE.md](../../USER_GUIDE.md) 为单一来源，原样随包交付供宿主读取，同时编入独立 UI 资源。Tether 页面提供“使用说明”按钮，弹窗按标题、段落、列表和代码块显示文本，支持 Escape 关闭并恢复按钮焦点，不依赖开发仓库路径、联网或额外文档服务；不执行 HTML。

### 工具应用布局（2026-10-22 已实现）

用户明确独立桌面应用并非必要，重点为 Oriel 内按工具应用展示。Tether 与后续同类插件共用宿主的应用布局能力，不显示浏览器地址栏和通用前进后退控件；业务导航、表单与操作由工具页面负责。宿主保留必要的窗口拖动、窗口控制与通用管理入口，插件内提供说明入口。刷新、重试和诊断建议按需放入菜单，避免重复标题和两层工具栏。

应用布局由 WebView 承载，入口声明 `presentation: "application"`，不按 Tether ID、URL 或端口写死，后续兼容工具无需逐个新增宿主路由。宿主说明入口通过顶层 `documentation: "USER_GUIDE.md"` 提供，不要求后台启动。独立使用继续保留现有浏览器方式，后台生命周期、权限和导航校验继续按各自契约处理。

## 3. 主机与映射（2026-10-22 已确认并实现）

主机是操作中心，主机与转发入口合并。每条映射只显示一行，包含名称、方向与端点、当前状态、启动、复制地址及更多操作。备注按需显示；当前连接、使用方、参数和日志展开查看，不另铺一份重复的运行规则列表。

主机提供编辑、添加映射、启动全部映射、停止此主机、测试 TCP 响应、生效参数、临时转发和删除。名称、备注和 SSH 目标供搜索，映射名称、备注和端口同样可搜索；状态筛选覆盖运行、未启动及异常／待处理。折叠状态在本机浏览存储中记忆，存储不可用不阻止使用。

主机编辑分为连接设置与端口映射。映射按行编辑，宽窗口字段对齐，窄窗口折行为卡片；支持连续新增、复制行、多选删除、撤销本次删除和批量粘贴。名称留空时按端点自动生成，默认监听回环；方向清楚标注由本机或远端访问目标。备注和规则 ID 复制按需展开；不再提供网页地址或“打开页面”。

粘贴支持制表符分隔和 JSON 数组，先预览再加入草稿；统一检查端口、地址和同一主机内的监听冲突。保存一次提交主机及其映射，失败保留输入。保存与启动分开，修改运行参数显示待应用，由用户确认实际连接影响范围后应用并重启。

删除映射、删除主机或从主机编辑中移除映射时列出计划引用与运行连接。删除主机可一次清理其映射与计划引用，明确选择保留运行连接，或停止连接后删除登记。删除计划不停止连接。内部主机、规则和计划 ID 不常驻列表，在详情提供复制。

计划选择以主机分组，支持全选、部分选择、搜索和清空。主机全选保存当时的规则 ID，新映射不自动纳入。计划卡片显示主机数与映射数，展开可查看成员。

### 排序与弹窗操作（2026-10-23）

主机、同一主机内已登记映射和计划使用专用手柄排序；手柄也支持 Alt+↑/↓。主列表调整完成后按配置版本保存顺序，稳定 ID、计划成员与实际连接保持不变；保存遇到外部修改时报告冲突。临时托管项和 SSH 配置来源项不参与登记排序。主机编辑中的映射同样可排序，顺序先留在草稿中，随“保存”提交。

长列表拖到可视区域顶部或底部时持续自动滚动，指针停在边缘也继续；弹窗内拖动滚动弹窗，主列表拖动滚动页面。放下、取消、失焦或组件卸载时结束自动滚动并清理拖拽标记。

所有弹窗使用固定顶部栏，关闭键保持在右上角，长内容滚动后仍可见；确认弹窗的关闭键执行取消。窗外关闭要求主指针在弹窗外按下并在弹窗外松开，窗内按下后移到窗外松开、反向跨边界和弹窗内边距点击均不触发关闭。编辑草稿的正常窗外点击继续遵循未保存确认。

### 单条映射的命令复制（2026-10-24 已实现）

每条映射的“更多”菜单在“复制规则 ID”下方提供“复制完整链接命令”。操作范围固定为当前这一条映射，即使它与其他映射共用一个 SSH 连接组，也只复制该条转发。

- 命令包含 SSH 程序、目标／别名、必要连接参数，以及当前映射对应的一项 `-L`、`-R` 或 `-D`；使用 `-F none` 避免重新继承其他转发，不引用连接组的临时运行配置文件。
- 已登记映射按当前已保存的主机与映射配置生成，未启动也可复制；存在“参数待应用”时仍使用已保存配置。临时托管项及 SSH 配置来源项从所属运行快照取出这一条，不要求仍有登记。
- 生效的用户、端口、身份文件、跳板及仅转发／保活参数由后台处理并经本机 OpenSSH 回读核对；密钥、Agent 与自定义代理仍使用对应环境原有资源，不导出密码、私钥口令或后台身份。不能可靠保留的配置明确报错；跳板参数中的 `%j`／`%C` token 当前拒绝导出。
- 复制内容直接调用 SSH，默认以 `ssh -N -T` 开头；常用身份文件、端口与用户使用 `-i`、`-p`、`-l`，其他参数使用 `-o key=value`。缺失或含延迟展开的身份路径保留原配置语义，不为了简短而丢失参数。Windows 命令粘贴到 PowerShell，已有 WSL 环境命令粘贴到该发行版的 POSIX shell，路径与身份跟随所属环境；有嵌套双引号时 Windows 在 SSH 调用内使用 `--%` 保留参数，不能无损传递时明确报错。自定义 SSH 程序按已配置路径调用，不额外包装 Windows 到 WSL 的启动命令。
- 点击只生成并写入剪贴板，不改变连接状态；成功提示“完整链接命令已复制”，生成与剪贴板失败显示可关闭错误。处理期间禁用重复复制，支持异步 ClipboardItem 时在点击期间取得写入入口，避免 SSH 解析耗时导致用户手势过期。
- 用户随后在终端执行的连接继续遵循外部连接只读边界，Tether 的自动重连、隐藏窗口与进程管理不随文本导出。

菜单与反馈复用现有组件和行菜单收起／焦点行为，后台以 `connectionCommand` 动作共享规则格式与 SSH 配置处理；前端不拼装另一套 SSH 参数。输入输出见[实现契约](../implementation.md)，本地／远程／SOCKS、同组隔离、临时项、参数待应用、两跳、路径引号、IPv6 和失败反馈的实际结果见[验证记录](../../verification.md)。

## 4. 操作范围

- 已登记且未启动的规则支持单独或多选启动。
- 同批按参数兼容性形成 SSH 连接组，开关或停止按钮对应实际组。
- 停止组清楚显示将影响的转发数与使用方，不能显示成只关闭一条规则。
- 临时托管项提供停止和保存为规则操作；保存不重启。
- 终端连接仅在匹配的已登记／临时映射上显示运行状态与来源；不提供外部连接总览或改变该进程的按钮。
- 相同规则已有旧参数运行时标记待应用，由用户明确重新启动。

“主机全部停止”与“所有主机全部停止”需区分文案和位置，两者都只影响托管连接。

## 5. 单一响应时间

每个主机只显示一个响应值，首次测试和主动测试更新同一位置；成功值使用成功色，测试中用强调色，无法测量用错误色并保留文字，避免仅靠颜色区分。默认测试目标 SSH 地址的 TCP 响应，方法与更新时间在提示或详情里查看。

不另设首次建立耗时、SSH 往返、服务响应等多个卡片，也不在同一主机每条转发上重复同一个值。跳板内目标无法可靠测试时显示无数据，不用猜测数值填充。

## 6. 配置与认证交互

常规入口只填写 SSH 目标／别名，用户随目标或原始配置提供；高级 User 覆盖与目标中的用户冲突时拒绝保存。常用表单、可搜索的 102 项参数目录与高级有序 `-o` 共用一份数据。目录基于 OpenSSH portable 10.0，枚举值使用选择控件，端口等使用数值输入，路径与开放取值使用文本；标明专用设置和托管限制，实际支持以本机解析为准。手动覆盖可以恢复继承，不将继承配置复制成另一份可编辑值。

生效预览以名称、值和可确认来源展示；不能可靠区分原始文件与 OpenSSH 默认值时统一标为“继承配置 / OpenSSH 默认”，不伪造准确文件来源。临时覆盖与保存配置分开，最终执行详情不显示密码或口令。

配置文件编辑以原文为中心，能够跳转到来源文件、调用外部编辑器、处理外部修改冲突。密钥与 known_hosts 入口区分客户端身份和服务器身份。

认证对话展示对应主机与连接任务，允许取消；临时转发在编辑弹窗中等待时，认证输入也显示在弹窗中，避免被模态界面阻挡。多个认证任务显示等待数量并逐个处理。前置动作触发认证时，应让用户知道是哪个页面需要该连接；没有界面可交互时返回明确等待或失败状态。

## 7. 状态与反馈

需要覆盖空列表、加载、启动中、等待认证、运行、重连等待、参数变化、端口冲突、启动失败、停止中和部分结果。

批量执行结束提供“复用、新启动、未就绪”摘要，支持仅重试未就绪的已登记映射，沿用本次覆盖参数。具体错误按项展开，并在对应主机或映射旁保留；错误可关闭，成功通知短暂显示。操作按范围显示忙碌，局部请求不锁住整个页面。

成功停止并完成清理后，运行记录自动移除，登记映射恢复未启动；不提供连接历史。失败记录保留诊断并允许关闭，重试时清理同一映射的旧失败记录。未保存的主机／映射／计划编辑在 Escape、关闭或取消时提供继续编辑、放弃或保存选择；支持 Ctrl/Cmd+S。刷新或关闭页面时使用浏览器的未保存保护；配置原文离页和重新读取同样保护草稿。

在 Oriel 中依赖连接暂时中断时，保留页面实例，显示必要连接状态与明确重试入口；不因状态轮询不断刷新网页或自动重跑被用户取消的前置动作。

## 8. 可用性与验证

列表、菜单、表单、分组折叠和批量选择均提供键盘操作与可见焦点。长名称、长参数、路径和备注应合理换行或展开；窄窗口将次要字段移到详情，保持核心操作可到达。

实施后分别检查浅深主题、长列表、小窗口、等待认证、错误反馈和停止组的范围提示。未经实际预览或验证，不将本设计稿当成界面验收通过。

## 9. 密钥列表（2026-10-22 调整）

进入密钥页自动读取文件与 Agent 信息。已登记文件以紧凑列表呈现，名称、私钥／仅公钥／文件缺失类型、Agent 状态、完整路径和 SHA256 指纹分层展示；支持按路径和指纹搜索。公钥复制和 Agent 加载为主要操作，口令、公钥备注及公钥详情在每个文件的更多操作内展开。不可用的文件操作禁用，错误就近展示；Agent 身份单列，不伪造本地文件路径，也不展示原始 JSON。

登记路径与新路径生成共用明确的路径输入，生成先登记后调用工具，避免原入口必须提前登记却没有提示。窄屏保持路径与指纹换行、操作可到达，并沿用现有浅深主题。
