# Tether

面向 Windows 的本地 SSH 与端口转发管理工具，可以独立运行，也可以作为 Oriel 的独立插件接入。

名称取连接与维系之意。核心原则是：**启动新转发时保护已有连接；同批尽量共用 SSH；关闭按连接组处理；外部连接保持不动。**

## 当前状态

设计基线日期为 2026-10-21。本仓库目前仅包含设计资料、开发约定和 Git 忽略规则，没有产品代码、构建入口、依赖或已实现接口；尚未执行任何真实 SSH、密钥管理或 Oriel 生命周期动作。

本目录是独立 Git 仓库，开发工作目录位于 Oriel 工作区的 `plugins/external/tether/`。父仓库忽略整个目录，既不是子模块，也不把工具源码随 Oriel 提交。该位置便于本机开新会话，不构成安装路径或运行时依赖；独立克隆到其他位置仍应可用。

## 已确认方向

- Windows 原生 OpenSSH，先做普通 SSH 转发，再完善主机、配置和密钥管理。
- 登记与临时转发、主机分组、备注、实时明确观测、单一响应时间、一键启动计划。
- 跳板链、密钥、`-o` 临时覆盖、静默及其他 SSH 参数尽量可配置；管理进程所需的约束由运行模式处理。
- Oriel 通过公共动作按规则 ID 请求转发，已有连接直接复用，转发就绪后才打开依赖页面。
- 完全退出 Oriel 时清理 Tether 托管转发；终端及其他程序创建的外部连接仅观测。
- Vue 3／TypeScript 界面、Rust 本地后台和系统 OpenSSH，独立使用与 Oriel 展示同一套页面。

配置字段、CLI 拼写、控制通道和依赖版本尚未冻结。文档中的命令与字段示例均用于交接，不是已经可执行的协议。
